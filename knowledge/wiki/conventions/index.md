# Conventions

Patterns this repository expects you to follow. When a convention is enforced by tooling, that is noted.

## Conventions

- [Code Style](code-style.md) - The style rules CI enforces on Dart, and the patterns every file follows with nothing enforcing them: alphabetical order, private initializing formals, UK spelling.
- [Pinned Versions](pinned-versions.md) - Everything is pinned exactly, from Flutter to GitHub Actions: where each pin lives and which pins are enforced rather than merely followed.
- [Spec-driven Delivery](spec-driven-delivery.md) - How work moves from spec to pull request here: the four specs documents, plan steps as branches, test ids in test names, and what to do when the plan is wrong.
